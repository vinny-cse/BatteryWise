# BatteryWise – Smart EV Battery Recycling Assistant

A simple responsive educational prototype for battery registration and recycling-status tracking.

## Run locally
1. Download or extract this folder.
2. Open `index.html` in a modern browser.
3. Register a demonstration battery and explore the dashboard.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish your website.

## Features
- Battery category and record registration
- Unique demo Digital Battery Passport ID
- Manual recycling status updates
- Dashboard totals and category breakdown
- Search and status filter
- CSV export
- Responsive layout for mobile and desktop

## Important limitations
- Records are saved using browser LocalStorage. They stay in the same browser/device and are not automatically shared with other users.
- Recycling statuses are entered manually; the app is not connected to a real recycler.
- Passport IDs are demonstration identifiers, not official certifications.
- This app does not recycle batteries or assess battery safety.

For real batteries, use authorised collection/recycling channels. Never open, dismantle, puncture, charge, or experiment with damaged or used lithium-ion batteries.
